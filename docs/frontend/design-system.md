# 前端设计系统

本文记录 `neutron-star` 当前稳定的视觉和交互规则。新增界面优先复用这些规则，而不是另起一套样式。

## 审美原则

### 简单、可靠优先

- 优先选择成熟、可预测的布局和交互模式，不用装饰效果弥补信息结构不足。
- 视觉层级主要通过留白、字重、字号和细边框建立，不依赖大面积阴影、渐变或动画。
- 动效只用于解释状态变化，不作为吸引力来源。

### 白色背景，蓝紫点缀

- 界面基底保持纯白或接近纯白的实色表面。
- 强调色只使用蓝色或紫色体系；同一区域不要同时堆叠多个强调色。
- 当前默认强调色为紫色，蓝色可作为等价替代方向。
- 文字、按钮和状态色必须满足清晰对比度。

### 拒绝透明界面

- 承载文字的页面、侧边栏、顶栏、标签页、弹层和输入区域必须使用不透明背景。
- 不使用毛玻璃、半透明 tab、透出底图的卡片或低透明度遮罩影响文字阅读。
- 需要弱化层级时使用实色浅灰、细边框或字号变化，而不是降低整个表面的透明度。
- 透明度只允许用于禁用态等短暂状态，不得成为主要视觉语言。

### 不做僵尸设计

- 每个可见控件都必须有真实用途、真实状态或真实后端能力。
- 不用静态假数据、假会话、假按钮或空壳入口占位。
- 后端能力尚未完成时，优先不展示；若必须展示说明状态，应明确标注“尚未开放”，不能让它看起来已经可用。
- 删除功能时同步移除对应入口，不留下点击无效果或永远显示固定内容的控件。

当前已知例外：侧边栏“最近会话”仍是静态占位，没有持久化或切换后端的真实能力。它视为待清偿的僵尸 UI，不应作为新模式复用。

## 布局

```text
┌─────────────────────────────────────────────────────┐
│                     [左栏] [底部] [右栏] [— □ ×]   │  40px 顶栏
├──────────────┬──────────────────────┬───────────────┤
│ 左侧栏        │ 对话区                │ 右侧栏         │
│ 232px / 190px│                      │ 232px         │
│              │                      │               │
│              │ Composer             │               │
│              ├──────────────────────┤               │
│              │ 空白底部面板          │               │
└──────────────┴──────────────────────┴───────────────┘
```

- 顶栏横跨整个窗口，只包含拖动区、底部面板开关、侧边栏切换和窗口控制。
- 切换按钮从左到右依次为“左侧栏、底部面板、右侧栏”，随后是窗口控制。
- 顶栏不显示产品名、模型名或页面标题。
- 只有顶栏空白区域可以拖动窗口；侧边栏、对话区和 Composer 不承担窗口拖动。
- 桌面宽度下侧边栏可平滑收起；窄窗口下作为左侧浮层打开。
- 跨越 720px 断点时，窄屏默认收起侧栏、宽屏默认展开；用户仍可通过顶栏按钮或快捷键手动切换。
- 窄屏侧栏打开后必须位于对话区和 Composer 之上，并按 `Esc` 或执行“新对话”后关闭。
- 主对话区不设置重复的页面标题栏。
- 页面框架默认不可选中文本；仅对话正文、配置内容和输入编辑器允许选择与复制。

## 字体

字体文件和字体族只在 `frontend/src/styles/fonts.css` 定义。

| 令牌 | 本地族名 | 用途 |
| --- | --- | --- |
| `--font-sans` | Neutron Sans | UI、按钮、导航、标题、对话 Markdown 正文 |
| `--font-mono` | Neutron Mono | 代码、配置、路径、快捷键、编辑器 |

不要在组件中直接写具体字体文件名。来源和许可见
`frontend/src/assets/fonts/README.md`。

聊天正文和界面文字统一使用黑体。当前没有长文阅读或文档导出功能，因此不保留宋体资源；只有出现明确的长文阅读需求时才重新引入，并同时评估字号、行高和包体积。

## 颜色

主要颜色通过 `frontend/src/styles/style.css` 的 `:root` 变量管理：

- `--background`、`--surface`、`--surface-subtle`
- `--text`、`--muted`、`--muted-light`
- `--border`、`--border-strong`
- `--accent`、`--accent-soft`
- `--danger`、`--danger-soft`
- `--success`

状态不能只依赖颜色表达，错误提示还需要文本或 `role="alert"`。

## 顶栏与窗口控制

- 顶栏高度 40px，空白区域是窗口拖动区。
- 窗口按钮宽 32px、高 30px。
- 鼠标悬停在窗口按钮、面板按钮和侧栏按钮上时使用普通箭头，不显示系统手形图标。
- 关闭按钮使用危险色悬停状态。
- 两个侧栏切换按钮位于三枚窗口按钮左侧，按钮之间间隔 8px。
- 双击顶栏空白处切换最大化状态。

## 侧边栏

- 默认宽度 232px；宽度低于 820px 时为 190px。
- 包含品牌、新对话、最近会话和模型连接状态。
- 收起时只改变布局，不改变对话内容。
- `Ctrl+B` / `⌘B` 与顶栏按钮执行同一动作。
- 宽度低于 720px 时使用浮层形式，避免挤压主内容。

## 右侧边栏

- 宽度 232px，当前保持空白，只提供布局和开关能力。
- 通过顶栏“右侧栏开关”或 `Ctrl+Alt+B` / `⌘⌥B` 展开、收起。
- 宽度低于 820px 时自动收起，手动展开后作为右侧浮层。
- 窄屏下同时只保留一个侧栏浮层；打开一侧会关闭另一侧。

## 底部面板

- 位于中间对话列的 Composer 下方，不横跨左右侧边栏。
- 启动时默认展开，只包含一块空白面板体，不显示标题栏或横向控制栏。
- 面板高度使用 `clamp(150px, 26vh, 240px)`，在矮窗口中自动缩短。
- 通过顶栏最左侧的底部面板图标或 `Ctrl+J` / `⌘J` 折叠、展开。
- 收起时高度直接归零，不保留横向残条或折叠把手。
- 当前保持空白，不显示假终端、示例日志或占位按钮。
- 后续用于终端、任务输出或其他真实工具视图。

## 对话区

- 欢迎态、消息列表和 Composer 共享居中的内容宽度。
- 用户消息靠右，assistant 消息靠左。
- 流式输出显示插入光标，并自动跟随到底部；用户主动上滚后停止跟随。
- 停止生成应显示“已停止生成”，而不是红色失败状态。

## Composer

- 使用 CodeMirror Markdown，Enter 发送，Shift+Enter 换行。
- 输入法组合状态中的 Enter 不得触发发送。
- 运行中按钮切换为“停止”。
- 输入区可编辑，但悬停指针使用普通箭头。

## 响应式断点

- `820px`：侧边栏缩窄，配置区改为单列。
- `820px`：右侧栏自动收起并切换为右侧浮层。
- `720px`：侧边栏变为浮层，隐藏快捷键提示和模型胶囊。
- 动画必须在 `prefers-reduced-motion: reduce` 下近似关闭。

## UI 验证清单

- 顶栏拖动与双击最大化正常。
- 侧边栏任意位置都不能拖动窗口。
- 三个窗口按钮、底部面板按钮和两个侧栏按钮都没有异常鼠标图标。
- 左右侧栏的展开、收起和快捷键状态一致。
- 右侧空白栏和底部面板没有混入静态假内容。
- 底部面板收起后不残留任何横向栏或空白条。
- 除对话正文、配置内容和编辑器外，拖动鼠标不会选中界面文字。
- 所有承载文字的表面均为不透明背景。
- 强调色只来自白色 + 蓝色或紫色体系。
- 每个可见按钮、标签和入口都有真实行为或明确不可用说明。
- 没有静态假数据或无后端支持的空壳功能。
- Markdown、代码块、长文本和空状态布局正常。
- 窄窗口中侧栏不遮挡无法关闭。
- 窄屏浮层打开时，Composer 永远位于侧栏下方，不能覆盖侧栏内容。
- 从宽屏缩到窄屏时，侧栏自动收起；从窄屏恢复到宽屏时，侧栏自动展开。
- 键盘可访问名称存在，焦点样式可见。
