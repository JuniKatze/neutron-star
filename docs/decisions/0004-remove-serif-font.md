# ADR-0004：移除未使用的宋体资源

- 状态：Accepted
- 日期：2026-10-17

## 背景

聊天正文最初使用本地 Noto Serif SC。实际检查后，12–13px 的中文宋体在低 DPI 屏幕上笔画和复杂字内部结构不够清晰；项目当前也没有长文阅读、文档预览或导出功能。继续打包宋体会保留约 5.5 MB 的未使用资源。

## 决策

- 删除 `NeutronSerif-Regular.woff2` 和对应许可证。
- 删除 `Neutron Serif` 的 `@font-face`。
- 删除 `--font-serif` 令牌。
- 聊天正文和界面文字统一使用 `--font-sans`。
- 保留 `--font-mono` 用于代码、配置、路径和编辑器。

## 后果

- 应用包减少约 5.5 MB。
- 字体体系只保留黑体和等宽两类，减少无用途配置。
- 如果未来实现真正的长文阅读模式，需要重新评估并新增 ADR；不能仅因为“想在某个标题上使用宋体”就重新打包整套中文字体。
